# Sistema de Controle de Estoque

Aplicação desktop desenvolvida em Python para cadastrar e controlar produtos de um estoque.

## Funcionalidades

- Login inicial;
- Cadastro de produtos com nome, quantidade e preço;
- Listagem dos produtos cadastrados;
- Exclusão de produtos;
- Entrada de estoque;
- Saída de estoque;
- Validação de campos e quantidades;
- Aviso de produto não encontrado;
- Proteção contra estoque negativo.

## Tecnologias utilizadas

- Python
- Tkinter
- CustomTkinter
- SQLite

## Como executar

1. Instale o Python 3.
2. Instale a biblioteca CustomTkinter:

```bash
py -m pip install customtkinter
```

3. Abra a pasta do projeto no terminal.
4. Execute:

```bash
py main.py
```
